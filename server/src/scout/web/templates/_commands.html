Claude Code

Run this in a terminal:

claude mcp add --transport http scout {{ mcp_url }} --header "Authorization: Bearer {{ token }}"

OpenAI Codex CLI

Codex reads the token from an environment variable called SCOUT_TOKEN. Add the server once:

codex mcp add scout --url {{ mcp_url }} --bearer-token-env-var SCOUT_TOKEN

Then set SCOUT_TOKEN wherever you start Codex. On macOS or Linux, add this line to your shell profile (for example ~/.zshrc or ~/.bashrc):

export SCOUT_TOKEN="{{ token }}"

On Windows, run this once in PowerShell, then open a new terminal:

setx SCOUT_TOKEN "{{ token }}"

Grok Bot

Paste this into a Grok Bot chat:

Add a custom MCP server called scout at {{ mcp_url }}/{{ token }}

Click Add it when Grok asks. Keep the word "custom", or Grok looks in its marketplace instead. Then attach Scout to a chat with @scout.
