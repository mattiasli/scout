# Protocols

Scout has two links. Each side of each link is written separately, so these documents
are the contract between them.

| Link | Between | Document |
|---|---|---|
| Serial (UART) | UNO ⇄ ESP32-CAM, or UNO ⇄ a PC for bench tests | [uart.md](uart.md) |
| WebSocket | ESP32-CAM ⇄ Scout server (and the simulated car) | [car-link.md](car-link.md) |

[`uart_vectors.txt`](uart_vectors.txt) holds test vectors for the serial framing. It is
generated by [`tools/make_uart_vectors.py`](../tools/make_uart_vectors.py), and both the
C++ tests (`firmware/tests`) and the Python tests (`tools/tests`) read it.

When you change a protocol, change the document, both implementations and their tests
in the same pull request.
